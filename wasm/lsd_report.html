fluent_scene technical report

LSDシェーダーの科学

LSDのトリップ映像は「なんとなくサイケな模様」ではなく、視覚系の配線から数学的に導ける現象です。fluent_sceneの新フィルタ lsd が、どの神経メカニズムをどの計算で再現しているかを解説します。

デモを開く(要カメラ許可) GitHub: fluent_scene 作者 @takatronix

Created by takatronix — fluent_scene / fluent_vision 開発者。デモはGitHub Pagesから配信され、映像処理はすべてブラウザ内(wasm)で完結します。カメラ映像がサーバーに送られることはありません。

fluent_scene とは

カメラ映像や画面に、リアルタイムで絵やエフェクトを描くための自作エンジンです。画面は数行の設定ファイル、エフェクトは1行で書けて、GPUで動くので速い。同じコードがロボットでもブラウザでも動き、この記事のLSDエフェクトもその1つです。AIに画面を作らせても壊れない設計になっています。GitHub で公開中(MIT)。技術的な中身は記事の後半で。

1. 何が見えるのか — 現象の分類

LSDの視覚効果は主観報告の集積によりかなり細かく分類されています(体系的なカタログとしてはPsychonautWiki Visual effects が最も網羅的)。主要なものは:

  • ドリフト(drifting) — テクスチャや輪郭がゆっくり波打ち、溶け、流れる。「壁が呼吸する」
  • 色彩増強(color enhancement) — 彩度・明度の主観的増強。赤はより赤く
  • トレーサー/残像(tracers / palinopsia) — 動くものが尾を引く。連続的なブラーではなくコマ送りの静止像の列として残るのが特徴
  • 幾何学的幻覚(geometric hallucinations) — トンネル・螺旋・放射・格子。閉眼や暗所、平坦な面に出やすい
  • 色収差・虹彩(diffraction) — 高輝度部の縁に虹色のにじみ
  • 視力の主観的鋭敏化(acuity enhancement) — エッジがくっきり見える

2. なぜそう見えるのか — 分子から大脳新皮質まで

2-0. そもそもなぜLSDは効くのか — 鍵と鍵穴、そして「蓋」

出発点は分子の形です。LSDの骨格の芯にはインドール環(ベンゼン環とピロール環が縮合した二環)があり、これは脳内の伝達物質セロトニンの骨格そのものです。つまりLSDは「セロトニンの形を含んだ、より大きく硬い分子」で、セロトニン受容体の結合ポケットに鍵のように嵌ります。

2017年、WackerらがLSDが結合したセロトニン受容体の結晶構造を解きました [13]。決定的な発見は、受容体の細胞外ループ(EL2)がポケットの入口に「蓋」のように被さり、LSDを閉じ込めること。この蓋のせいでLSDは受容体から異常に解離しにくく(数時間居座る)、トリップが8〜12時間続く理由がここにあります。蓋の可動性を上げる変異を入れると解離が速くなり、シグナル伝達の偏り(βアレスチン経路)も消えることまで確認されています。

まとめると: インドール環の形状一致で5-HT2A受容体に嵌り、EL2の蓋で長時間ロックされ、皮質の興奮バランスを持続的に崩す——これが以降のすべての視覚現象の分子的な起点です。

2-1. 5-HT2A受容体 → 皮質ゲインの上昇とゲーティングの崩れ

LSDの主作用はセロトニン5-HT2A受容体の作動です。これが皮質錐体細胞の興奮性を引き上げ、同時に視覚野のアルファ律動(入力を「間引く」ゲート役)を減衰させます [4][6]。さらにfMRI研究では視床—皮質間の結合が増強し、視床による感覚フィルタリングが弛むことが視覚性幻覚の強度と相関することが示されています [5]。要するに「入力のゲインが上がり、選別が甘くなる」——色が濃く、エッジが鋭く、些細なパターンが意味ありげに見える状態です。

2-2. 幾何学模様の正体 — V1の自己組織化と対数写像、そしてフラクタル

幾何学的幻覚は1926年にKlüverがメスカリン研究で4類型に整理しました(form constants: トンネル/漏斗・螺旋・格子・蜘蛛の巣)[1]。なぜ誰が体験しても同じ図形になるのか——1979年、ErmentroutとCowanが美しい説明を与えます [2]。

第一次視覚野(V1)のニューロンは「近くを興奮させ、少し遠くを抑制する」側方結合を持ちます。薬物で興奮が底上げされてこのバランスが崩れると、皮質シート上に活動パターンが自発的に立ち上がります(化学反応のTuringパターンと同族の分岐現象)。ここで効いてくるのが、網膜からV1への投射が近似的に複素対数写像 (x,y) → (log r, θ) になっているという解剖学的事実です。皮質上の平行な縞を逆写像で「見え」に戻すと:

  • 縞が log r 軸に垂直 → 同心円 = トンネル
  • 縞が θ 軸に垂直 → 放射状 = 漏斗・光条
  • 斜めの縞 → 対数螺旋
  • 2方向の縞の重なり → 格子・市松

ただし単一の平面波(=規則正しい1枚の縞)では、体験者が語る「大小さまざまな塊がフラクタルに入れ子になって流れてくる」質感は出ません。ここには2つの科学的根拠があります:

  • 格子プランフォーム — Bressloffらの拡張理論 [3] は、V1の方位選択性コラム間の異方的な側方結合(shift-twist対称性)まで含めると、安定解が単独の縞ではなく菱形・六方格子上のパターン(honeycomb・cobweb・filigree)になることを示しました。Klüverの「格子」「蜘蛛の巣」類型はここから出ます。
  • フラクタル次元の増大 — Varleyら [10] はLSD・シロシビン下のfMRIで、皮質活動のフラクタル次元が空間・時間の両ドメインで増大することを実測しました。臨界に近づいた系はスケールフリー——特定の「支配的な波長」が消え、あらゆるスケールの構造が同時に立つのです。

ただし理論の「格子解」をそのまま三角関数で描くと、規則正しすぎて嘘になります。体験報告に共通するのは「直線・直角・真円が存在しない」こと、そして「3Dの中を飛んでいて、すべてが永遠に拡大し続ける」感覚です。そこでシェーダーの幾何場は周期関数を一切使わず、次の構成にしました:

  • 永遠の拡大(eternal zoom) — スケールが2倍ずつ違う3枚の深度シェルをハン窓でクロスフェード。飛行が進むと手前のシェルは窓の外へ膨張して消え、新しい遠景シェルが湧く。整数の「飛行インデックス」で毎回内容を取り替えるため、拡大は終わらず、二度と繰り返しません
  • 自然な微細ディテール — 各シェルは高周波寄りの4オクターブ値ノイズをドメインワープしたもの。大きな流れの縁に、より細かい房状の構造がどこまでもぶら下がる——自然物の細かさ(海岸線・雲・地衣類)と同じ統計です
  • 奥行きの手がかり — 手前のシェルほど明るく、max合成で「手前が奥を遮る」。各シェルが黄金角で離れた固有の色相を持つため、奥行きが色でも分離して見えます

Klüverの類型は描かれた図形としてではなく、多スケール性・流動・中心偏重という統計として生き残ります。フィードバック(後述)の吸い込みと合わせると、画面全体が奥から湧いて迫ってくる飛行感になります。

下のデモで基本原理を確かめられます。左が皮質シート上のパターン、右がそれを網膜座標に逆写像した「見え」です。「入れ子格子」がシェーダーの多オクターブ構成に対応します:

皮質の縞  ──  逆写像 r = e^u, θ = v  ──>  知覚される図形

2-3. 残像とトレーサー — モーションストリーク抑制の破綻と「再帰」

通常、脳は動体が網膜に残す「ブレ跡」を能動的に消しています(motion streak suppression)。LSDはこの抑制回路を動作範囲外に追いやり、消されるはずの過去フレームが知覚に残り続けると考えられています [7]。重要なのは報告の質感で、滑らかなブラーではなく離散的な静止像の連なり(ストロボ的なコマ)として尾を引きます。

これは計算としてはフィードバック(出力の再入力)です。1パスのシェーダーには前フレームの記憶がないため、デモでは描画結果を毎フレーム取り出し、わずかに拡大・回転・減衰させて次フレームの入力に合成しています。この再帰が、トレーサーだけでなくトンネルの奥行きが無限に増殖するフラクタル感も生みます——ビデオフィードバック(カメラでモニタを撮る)と同じ力学です。

2-4. なぜ同じ映像は二度と現れないのか — 非定常性

LSD体験のもう一つの署名は非定常性です。映像は静止した「エフェクト」ではなく常に変容し続け、同じ状態は二度と戻りません。切り替わりも一様ではなく、気づいたら変わっていた・ゆっくり滲むように変わった・パッと切り替わった——の全てが起こります。これも実測と整合します:

  • シロシビン下の脳は通常時より広い動的状態レパートリーを遍歴します(Tagliazucchiら [11])。LSD下ではコネクトーム・ハーモニクス(脳活動の固有モード)の使われ方が拡張し、状態軌道が反復しなくなります(Atasoyら [12])。
  • Varleyら [10] の時間方向のフラクタル次元増大は、変動が特定の時間スケールを持たない(スケールフリー)ことを意味します。べき則的な変動には「ゆっくりの漂い」と「突然の転移」が同じ分布の裾と胴として共存します——「パッと/ゆっくり」の両方が起こるのは偶然ではありません。

デモではこれを「トリップ導体」として実装しました。全パラメータがスライダー値を基線に彷徨い続けます: ①各パラメータに非通約な周波数の微揺らぎ(気づかぬ変化)、②ポアソン到着(平均約20秒)のメタ安定ジャンプ。ジャンプの遷移時間は0.25〜20秒の対数一様分布(重い裾)から引くため、あるときは一瞬で、あるときは1分近くかけて別の様相へ滑ります。さらにフィードバックループ自体が非線形再帰なので、初期条件に鋭敏——厳密に同じフレームは二度と生成されません。

4. パラメータで遊ぶ

デモは takatronix.github.io/fluent_scene/lsd.html(GitHub Pages・https配信なのでそのままカメラ許可が通ります)。映像は全画面表示で、操作は右上の ⚙ で開くドロワーに収納。⛶ またはダブルタップで全画面、スマホは最初のタップで自動的に全画面へ入ります。「薬理」群がフィルタ本体、「再帰」群がフィードバック、「変容」群がトリップ導体です。

  • トリップ — マスターゲイン。0で素通し、1.5で全ステージ最大。「用量」に相当
  • ドリフト — うねり・呼吸の振幅。3まで上げると壁が溶ける
  • 幾何幻覚 — form constantsの重畳強度。暗い場所・平坦な面ほど出る(実際の報告と同じ)
  • 色収差 — 虹のにじみ幅
  • 残像 — フィードバック減衰。0.9超で過去が消えなくなる
  • 吸い込み — 再帰時のズーム。正で奥へ吸い込まれ、負で湧き出す
  • 渦 — 再帰時の回転。残像と組むと対数螺旋が自然発生
  • 自動変容 / 深度 — トリップ導体のON/OFFと振れ幅。ONの間、全パラメータはスライダー値を基線に彷徨い続け、二度と同じ映像になりません。ステータス行に「滞留/転移中(パッ・ゆっくり)」の状態が出ます

おすすめレシピ

  • 閉眼幾何: カメラを手で塞ぎ、幾何幻覚1.2・トリップ1.0 — 入力が消えると内因性パターンだけが残る(暗所で模様が見える現象の再現)
  • ストロボ残像: トレイル「発光残像」・残像0.85で手を振る — 論文[7]の言う離散的トレイル
  • 無限トンネル: 残像0.9・吸い込み0.3・渦0.2 — ビデオフィードバック力学
  • 低用量: トリップ0.3・幾何0 — 色が少し濃く、輪郭が少し揺れるだけ。閾値用量の記述に近い

5. 実装メモ

フィルタ本体は include/fluent_scene/shared/filters_shared.h の fs_lsd() 1関数(GLSL∩C++単一ソース)で、CPU・Vulkan・WebGPU(naga経由WGSL)の3バックエンドで同一コードが走ります。ゴールデンテストでCPU↔GPU差は max_diff=4/255。時間は time スロットをホストが毎フレーム駆動する方式(fx::Ripple と同じ)で、time=0 なら静止し決定論的にテストできます。フィードバックはフィルタパイプラインの外(デモ側)で閉じており、コアのレンダラは無改造です。

// 幾何ステージの核心部(fs_lsd抜粋): 永遠に拡大する深度シェル
float zp = t * 0.3;                        // 飛行速度(オクターブ/秒)
float zf = zp - floor(zp);
for (int i = 0; i < 3; ++i) {
    float e  = float(i) - zf;              // 深度指数(手前ほど小さい)
    float sc = exp2(e);                    // 縮む → 画面上では膨張
    float m  = float(i) + floor(zp);       // このシェルの飛行インデックス
    vec2  off = hash(m);                   // シェルごとに新しい内容
    float w  = 0.5 - 0.5*cos(2.094*(e+1)); // ハン窓: 湧いて→育って→消える
    vec2 pl = pc * 3.0 * sc + warp * 2.2 * sc + off;
    float nv = vnoise(pl) * 0.38 + vnoise(pl * 2.1) * 0.27   // 高周波寄りの
             + vnoise(pl * 4.4) * 0.2 + vnoise(pl * 8.9) * 0.15;  // 微細構造
    float near_f = smoothstep(2.0, -1.0, e);
    float clv = smoothstep(0.52, 0.72, nv) * w * (0.5 + 0.5*near_f);
    mass_ph = clv > mass ? m*2.39996 + ... : mass_ph;  // シェル固有の色相
    mass = max(mass, clv);                 // 手前が奥を遮る = 3D
}
この実装は視覚現象の計算論的な近似であり、薬物体験の完全な再現でも、薬物使用の推奨でもありません。点滅・渦巻きパターンは光感受性の方には刺激が強い場合があります。パラメータは控えめな値から試してください。
