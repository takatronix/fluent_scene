LSDフィルタ 実装レポート セロトニン作動性の視覚現象学を、文献に載った機構ごとにシェーダーへ写す

fluent_scene の lsd フィルタは「サイケデリック風」の 見た目クリシェ集ではなく、LSD の視覚体験について神経科学の文献が記述する 現象を段ごとに実装したものです。各段が「何の現象を」「どの機構の報告に 基づいて」「どう描いているか」を、このレポートで対応づけます。

0. 全体の設計原則

トリップの視覚には直線も直角も真円も現れない — 報告される幾何は常に 有機的で、あらゆるスケールに同時に構造がある。そこで本フィルタの幻覚場は 構成的に非周期です: 正弦波の壁紙や同心円をどこにも置かず、ドメイン ワープした value-noise の fBM を土台に、6 段のオクターブ梯子全体がスケール 空間をすべり続ける「永久ズームフラクタル」(64×のスケール域を循環、各段は 生成消滅時に新しい内容で再シード)として描きます。中心は固定 — 体験には 常に中心があり、永遠の拡張はそこから放射する、という現象学の再現です。

1. 現象 → 機構 → 実装の対応表

現象（体験の言葉）機構（文献）実装（シェーダー段 / パラメータ）
ドリフト・呼吸 — 壁や質感がゆっくり波打ち「息をする」 5-HT2A 作動が皮質ゲインを上げ、視覚野の α 波ゲーティングを抑制。 α 抑制の強さは単純幻視の強度と相関 [4] 1 周期未満の放射呼吸波 + ノイズ場をレンズにした変位 （drift）。変位は中心でゼロ — 画面全体が平行移動せず「揺らぐ」
色フリンジ — 明るいエッジに虹の縁取り 散瞳（瞳孔拡大）による軸外収差の増大 周辺ほど強い放射方向の R/B 分離（chroma）
鋭敏化・色の氾濫 — 細部が刺さり、彩度が上がる 視床のゲーティング低下 = フィルタされない感覚駆動が皮質へ [5] アンシャープ + 彩度リフト + ゆっくりした色相の「呼吸」（trip）
幾何幻覚 — 格子・トンネル・らせん（form constants） Klüver の form constants [1]。V1 の興奮/抑制不安定性が自発的に パターンを自己組織化 [2][3]。LSD は皮質活動のフラクタル次元を上げる [8] 永久ズーム fBM の多スケール塊抽出（geometry、符号で 有機⇔デジタル）。Klüver の類型は「描いた図形」ではなく統計 （多スケール・流動・中心密）として現れる
純色 — 赤・緑・青・黄・シアンは出るが紫がほぼ出ない （現象報告からの設計）原色の空間的な錯位として解釈 粗い段のみ R が前方・B が後方に読む「プリズム錯位」。 重なりは黄/シアン/白を作り、G 抜きの R+B（紫）はほぼ生じない
非定常性 — 同じ絵は二度と来ない。変化は「パッ」とも、 気づかないほどゆっくりとも起こる 脳の動的状態レパートリーが拡張 [6][7]、時間ゆらぎがスケールフリー化 [8] デモ側の「指揮者」: 各パラメータが基準値の周りを微揺動しつつ、 ポアソン到着の転移（遷移時間は 0.25–20 s の対数一様）で準安定状態を渡り歩く
パリノプシア・トレーサー — 動くものが残像の列を引く 視覚的残効の持続（HPPD 研究などで記述される陽性残像） フレーム間フィードバック（デモ側）: 前フレームの出力を減衰・ 微ズーム・微回転して再入力。lighten は離散残像、 source-over は滑らかなスメア。幻覚した幾何も再帰する — トンネルが咲くのはこのループ
視線との結合 — 見つめた場所が深くなる （体験報告からの設計）注視点周りで幻覚が組織化する MediaPipe 虹彩ランドマークによる視線推定。フィードバック渦の 中心が視線に追従し、カメラとのアイコンタクトで trip が深まる
閉眼幻視（CEV） — 目を閉じると幻覚が一段強くなる 網膜入力が絶たれ、内因性活動が視覚野を支配する。Klüver の form constants はもともと閉眼・暗所での観察が中心 [1] 目を閉じ続ける（まばたきではなく 0.35 s 以上）と検出し、 カメラ入力を漸暗 → 幾何の駆動源が「弱い網膜駆動」側へ倒れて 幻覚場が支配。geometry/trip/chroma/ 残像持続が同時に立ち上がり、目を開けると現実へ戻る

2. なぜ「情報密度」なのか

初期実装は丸い塊のノイズで、ラバランプのように見えました。トリップの 幾何がそう見えない理由は情報密度にあります: どのスケールを見ても 新しい構造があり（フラクタル次元の上昇 [8]）、輪郭は尖り、折れ、 決してバブル状に丸まらない。現在の実装は ridged 折り返しと永久ズーム梯子で これを描きます — 近づいても構造が尽きず、飛行は終わらず、繰り返しません。

3. 実装上の制約（正直な注記）

time はホストが毎フレーム渡す秒数で、既定 0 では静止 — だから golden テスト可能です（CPU / Vulkan / WebGPU の3バックエンドが 同一出力であることをピクセル比較で保証）。フレーム間フィードバック （トレーサー・再帰トンネル）は単一パスのフィルタ本体には持てないため、 デモページ側でループを閉じています。つまり lsd フィルタ単体は 「その瞬間の幻覚」、デモは「時間の中の幻覚」です。

フィルタ本体は GLSL∩C++ の単一ソース （filters_shared.h）で、CPU は C++ として、Vulkan は GLSL→SPIR-V として、WebGPU は SPIR-V→WGSL 機械変換として同じ数式を 実行します。手書き移植はありません。

4. これは何ではないか

本フィルタは薬物使用を推奨するものではなく、文献に記述された視覚現象の 計算論的な再現・可視化です。また「LSD の見え方の完全な再現」でもありません — 意味的な変容（顔貌の変化、パレイドリア、意味の過剰付与）はテクスチャ フィルタの守備範囲外です。
